## Notes for Claude Code
- Status taxonomy in use: plan approved -> admin structure named -> RFA issued -> subawards announced -> funds obligated
- Several states (WV, OH, GA, AL) have moved past "subawards announced" into active disbursement — consider whether the taxonomy needs a 6th stage for implementation/reporting.
- `awards.amount` is in raw USD (integer), not millions — format for display in the UI, don't alter the seed values.
- Every status_events row must carry its own source_url; don't rely solely on the sources table for citation on a specific claim.
